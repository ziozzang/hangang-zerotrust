# ADR 0012: 독립 분산 런타임 권한

상태: 필수 방향 확정. 분산 구현·검증은 진행 예정.
ADR 0010의 품계 내장 전용 런타임과 Hangang 정책 소유를 대체한다.

호패·수문장·품계는 각각 독립 배포 서버여야 한다. Hangang은 네이티브 인증/집행
게이트웨이와 통합 관리 호스트다. 논리적 통합은 공유 프로세스/공동 쓰기 DB를 뜻하지 않는다.

호패는 다중 인증·수명주기·인증 변환, 수문장은 IP/네트워크 근거, 품계는 정책 게시·
권한 매트릭스·판단을 소유한다. 각 서버가 저장·리비전·감사·상태를 소유한다.
Hangang은 범위가 제한된 인증 계약으로 관리를 위임한다.

원격 통신은 mTLS 또는 동등한 서비스 인증, 고정 엔드포인트와 근거 출처 보존이 필요하다.
현재 루프백 전용 HOP1/HGD1과 품계 내장 코어만으로 원격 서버 요구를 충족하지 못한다.
코덱/코어는 재사용하되 독립 품계와 네이티브 원격 인증 전송을 구현한다.

연결 재사용·제한된 큐/동시성/시간·배치/파이프라이닝·불변 컴파일 스냅샷을 사용한다.
요청마다 분석 저장이나 불필요한 JSON/DB 처리를 하지 않는다. 선택 캐시는 1~5초로
제한한다. 복제 노드는 게시/철회 lease·최소 리비전·만료 정책을 갖추고, 장애/오래된
권한이 묵시적 허용으로 바뀌지 않게 한다. 서킷과 노드 전환도 권한·서비스/tenant
범위·요청 상관관계를 보존한다.

세 독립 실 프로세스, 원격 인증/위조, 복제 CAS/철회, 혼합 인증과 서비스별 출력,
네이티브/HTTP 동등성, 통합 관리, 지속 1만/10만 판단 처리와 종단간 성능을
지연·포화·장애 기준과 함께 검증한다. 단독 벤치마크를 전체 처리량으로 주장하지 않는다.
이전 중 현재 동작하는 통합을 유지한다.
