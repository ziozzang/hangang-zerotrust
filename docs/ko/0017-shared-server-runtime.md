# ADR 0017: 공용 서버 런타임과 독립 판정 코어

[English](../adr/0017-shared-server-runtime.md)

상태: 경계 설계 확정. [hangang-runtime](https://github.com/ziozzang/hangang-runtime)
81352ef에 첫 gRPC 전송 기반을 구현했다. 품계 878bd2a와 수문장 65856ab 적용 및 로컬 검증을 마쳤으며,
호패 e1aead3도 추가 gRPC 인증 경로에 적용했다. 한강의 세 gRPC 클라이언트도 구현 및 로컬 검증을 마쳤다. 전체 요청 체인·K8s·운영 도입은 미완료다. 통합 패키지 전체의 완료를 의미하지 않는다.

TLS 파일 제한, 필수 클라이언트 인증서, 연결 수 제한, TCP_NODELAY,
gRPC 스트림·헤더 제한과 요청 제한 시간을 공유한다. 자격 역할, 메시지 크기,
전체 판정 처리량과 실제 판정은 각 도메인이 소유한다. 순수 판정 코어에는
HTTP/gRPC 의존성을 넣지 않는다. 요청은 기존 메모리 스냅샷을 사용한다.
요청 시간 제한은 블로킹 작업을 강제로 중단하지 않으므로 핸들러도 제한을 지켜야 한다.

네이티브 연결, 종료·드레인, 감독 실행·리스너 인계, 상태·관측과 스냅샷 발행
기반은 후속 공용화 대상이다. 공급자·세션은 호패, 권한 메타데이터는 품계,
네트워크 정책은 수문장, 라우팅·집행은 한강이 계속 소유한다. 저장 트랜잭션,
정책 컴파일과 원천 데이터의 신선도 규칙도 각 도메인의 책임이다.

고정 리비전을 사용하며 각 서버의 전송 의미, 감독 실행과 실제 K8s 기능을
별도로 검증한다. 독립 서버의 확장 구조를 유지하고 공용 다중 쓰기 업무 DB를 만들지 않는다.

## 로컬 검증 근거

품계 서버 테스트 17개, 수문장 서버 테스트 35개 및 양쪽의 엄격한 workspace Clippy가 통과했다.
실제 gRPC·네이티브 mTLS 요청, 자격 분리, 입력 제한, 리비전 조건과 정책 변경을 검증했다.
수문장은 감독 실행 HUP에서 리스너 인계와 정책 리비전 유지도 확인했다.
서명 업데이트·정책 보존·실패 롤백·변조 거부·취소의 회귀 검사도 통과했다.
이는 격리된 로컬 프로세스 검증이며 실제 K8s gRPC 배포나 운영 반영의 증거는 아니다.

호패 e1aead3은 실제 mTLS gRPC에서 세션 허용·HTTP 상태/사유 일치·동일 채널의 즉시
세션 종료 반영·잘못된/중복 호출 자격·자격 헤더 주입·인증서 누락 거부를 검증했다.
설정 검사는 필수 mTLS·호출자 인증·서로 다른 리스너를 확인한다. 전체 all-features
테스트 914개가 통과했으며 기존 환경 의존 테스트 42개는 제외됐다. 엄격한 Clippy와
영어·한국어 문서 검사도 통과했다. 관리자 상태에 실제 gRPC 주소를 표시한다.
컨테이너 빌드에 protoc·스키마·LDAP vendor를 포함했지만 컨테이너 빌드와 실제 K8s
배포는 아직 별도 검증이 필요하다.

한강 59e531d에 `pumgye_authority.transport=grpc`로 선택하는 품계 gRPC 판정 클라이언트를
추가했다. 기본 전송은 네이티브다. 실제 품계 서버를 사용해 mTLS 호출·관리자 자격 거부·
서버 이름 불일치 거부·게스트/복수 권한 거부·동일 채널 정책 회수·리비전 하한을 검증했다.
집중 테스트 7개와 설정 테스트 34개, 엄격한 Clippy, 문서·공개 검사가 통과했다.
전체 처리량·전체 묶음의 시간·입력 크기·묶음 리비전 일치 제한을 적용했다.
호패·수문장 gRPC 클라이언트, 실제 한강 요청 체인 전체, 자격/채널 수명 검증과
K8s·운영 반영은 미완료이며 gRPC 애플리케이션 프록시 완료를 의미하지 않는다.

한강 42cc000에 수문장 gRPC 클라이언트를 추가했다. `--guard-decision-grpc`로 선택하며
설정된 판정 주소와 필수 mTLS를 사용한다. 수문장 83092e6의 격리 도구로 실제 집행
허용/거부·동일 채널 차단 해제/복구·관리자 자격 거부·서버 이름 불일치·HTTP 우회 없음·
취소를 검증했다. 네이티브 일치와 감독 실행 리스너 인계도 함께 통과했다.
관련 테스트 22개(기존 1개 제외), 엄격한 Clippy, 문서·공개 검사가 통과했다.
입장 판정과 강제 권한 근거는 관측한 리비전을 공유하므로 HTTP 신호·네이티브/gRPC
질의가 섞여도 오래된 응답으로 후퇴하지 않는다. 선택 입장은 설정된 장애 정책을 따르며
품계에 필요한 네트워크 근거는 실패 시 사용 불가다. 호패 클라이언트·전체 한강 요청
체인·K8s/운영 배포는 아직 검증되지 않았다.

한강 0125779에 호패 gRPC 클라이언트를 추가했다. 공급자와 독립된 hopae-grpc 계약
크레이트(호패 7b5a8b8)를 고정해 사용한다. 호패 시나리오 9469182가 실제 한강
클라이언트를 세션 엔진에 연결해 로그인 허용·잘못된 키·서버 이름 거부·동일 채널
세션 종료를 검증했다. 클라이언트 5개·설정 34개·실제 HOP1 프록시 회귀 1개 테스트,
엄격한 Clippy, 영어/한국어 문서·공개 검사가 통과했다. 기존 인증 상태·반복 쿠키·
신원·종료 응답을 사용하며 HTTP/네이티브 우회나 판정 캐시를 추가하지 않는다.
콘솔 SSO는 아직 HOP1이다. 전체 실제 게이트웨이 체인·채널/자격 수명·K8s·운영
반영과 전체 목표는 여전히 미완료다.

## 실제 네 프로세스 요청 체인 검증

호패 도구 6107b4c로 실제 한강·호패·수문장·품계와 HTTPS 보호 라우트를
검증했다. mTLS HOP1/PPG1/HGD1 및 세 판정 모두 gRPC인 경우가 통과했다.
범위는 API 키/외부 API 릴레이 서비스 신원, 네트워크 근거, 서비스/IP/등급/메서드
권한, 게스트/잘못된 자격 거부, 서비스 격리, 자격 소비, 권한 회수/복구,
네트워크 차단과 원천 장애다. 거부 요청은 실제 애플리케이션 백엔드 호출을 늘리지 않는다.
수문장 장애/재연결 및 품계 재시작 후 회수 유지가 통과했다. gRPC에서는 호패를
재시작해도 영속 프로파일 삭제가 초기 파일에서 되살아나지 않았다. 두 전송의 외부
API 장애는 열린 서킷의 추가 호출 억제를 검증했다. 기존 세 프로세스 회귀 검사도 통과했다.

선택된 로컬 API 서비스 요청 체인의 근거이며 모든 신원 흐름·스트림 모드·일반
메타데이터 어댑터·실제 K8s·릴리즈/운영·분산 성능의 완료는 아니다. 관리자 UI와
K8s 패키지 검증도 별도 작업이다. 이번 기능 검증에서는 벤치마크를 수행하지 않았다.

## 공용 관리 TLS와 콘솔 위임

런타임 039166b(0.1.1)에 필수 클라이언트 인증서 TLS 파서와 제한된 HTTP/1.1 관리
HTTPS 수명주기를 추가했다. 수문장 7851660의 --management-tls는 판정 신원/CA를
사용하고 수집자/관리자 역할 및 감독 실행 리스너 인계를 유지한다. 품계 6708e1d와
호패 6411523도 기존 전송의 TLS 파서를 공유한다. 판정과 품계의 인증서 감사 신원은
각 도메인에 남는다. 수문장 35개·품계 17개·호패 네이티브 시나리오 14개(기존 1개 제외),
각 소비자의 엄격한 Clippy가 통과했다. 실제 HTTPS/gRPC 역할/인증서 거부·HUP 및
품계 HTTP/PPG1/gRPC 회수/복구도 확인했다.

한강 8c1c78d는 플러그인별 mTLS·사설 CA·DNS/SNI 검사·독립 연결 풀을 제공한다.
플러그인 테스트 6개·엄격한 Clippy 및 실제 한강 관리 API에서 독립 수문장 HTTPS
정책 조회/변경을 검증했다. 자산 해시·작업 감사·브라우저의 자격/TLS 경로 비공개는
유지한다. 최신 관리 변경의 K8s/운영 적용 및 전체 브라우저/공급자 관리 검증은 미완료다.

호패 ee94562에 선택 설정 listen.admin_tls와 공용 제한 HTTPS를 추가했다. 런타임
ba1a06c는 실제 TCP ConnectInfo를 유지하고 TLS 연결에 클라이언트 인증서가 있을 때
검증된 접속 증거를 서버가 주입한다. 호패 서명 위임은 루프백 또는 그 증거를 요구하며
HTTP 헤더로 위조할 수 없다. 기존 서명·세션·권한·인증 수준 검사는 계속 필요하다.
실제 로컬 mTLS에서 인증서 거부·로그인 거부 유지·종료를 검증했고 설정·전송 위조·기존
서명 배우 시나리오도 통과했다. 전체 테스트 917개 통과·기존 42개 제외 및 엄격한
Clippy·문서·공개 검사 통과. K8s 원격 관리 위임·호패 브라우저 관리·연합 SSO는 미검증이다.
