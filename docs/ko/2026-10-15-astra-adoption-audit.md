## 실제 관리자 확인과 재현 결함

새 익명 브라우저에서 로그인과 모든 JavaScript가 오류 없이 로드됐다. 새 system-admin
브라우저에서 품계·수문장·호패 메뉴와 화면이 오류 없이 열렸다. 사용자가 겪은 원래
계정·세션까지 정상이라는 의미는 아니며 해당 증상은 확인 중이다.

실제 품계 화면의 폼·원시 JSON 정보구조는 미완이다. 390px viewport에서 품계 페이지가
약 619px까지 확장됨을 재현했다. 같은 검사에서 수문장·호패는 390px 안에 머물렀다.
ADM-06의 실제 결함이며 전체 관리자 접속 불가를 입증한 것은 아니다. 해당 레이아웃
수정과 반응형 회귀를 다음 작업으로 진행한다.

## 릴리즈와 추가 범위

한강 0.3.7·호패 0.0.8·품계 0.1.7·수문장 0.3.6은
[릴리즈 기록](2026-10-15-native-observed-adoption.md)에 서명 공개·내부 반영 근거가 있다.
호패 0.0.9 조합 인증은 static/로컬·1,017개 테스트 근거가 있으나 실제 K3s 전체 검증이
아직 끝나지 않았다. 최초 브라우저 실패와 이후 catalog 복원 거부를 보존했으며 미공개다.
Workload 정책 C단계 머지·프로토콜 A단계 로컬 완료·원천 owner B단계 구현 중이고,
Workload/Human 전체 원천→백엔드 경로 검증은 미완이다.

기존 Astra 관리자 원문 3개는 보존했다. 중단되어 저장되지 않은 navigation/write-safety/style
후속 초안은 완료한 설계로 세지 않는다. 기존 큐 문단은 과거 기록이며 이 감사와 정확한
릴리즈 근거를 현재 상태로 사용한다. 상세 소스별 비공개 감사도 무결성 manifest와 보관했다.

## 후속 품계 레이아웃 후보
