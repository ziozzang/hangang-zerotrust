# 전체 구조와 소유권

[English](../ARCHITECTURE.md) · [목차](README.md)

Hangang은 라우트·리스너·백엔드·요청 집행을, Hopae는 프로바이더·사용자·세션·인증 강도를,
Guard는 IP/ASN/GeoIP·네트워크 위험을 소유합니다. 카탈로그는 리소스와 정보등급을,
정책 권한 주체는 접근 조건을 관리합니다. 같은 문서를 여러 서비스가 쓰는 구조로 만들지 않습니다.

제어 경로는 관리 콘솔 → 권한 주체 → 검증·컴파일 → 호환 번들 → CAS·원자적 게시 →
Hangang의 불변 스냅샷입니다. 카탈로그와 정책의 호환성을 함께 검증하며,
서로 다른 버전을 임의로 섞어 집행하지 않습니다.

요청 경로는 보호 네임스페이스와 리소스/작업을 먼저 확정하고 Hopae·Guard의 확인된 근거를
결합한 뒤 최종 정책을 집행합니다. 네트워크 허용은 사용자·리소스 권한을 대체하지 않습니다.
객체·테넌트·행 단위 접근은 애플리케이션의 실제 메타데이터와 연계합니다.

현재 컴포넌트의 일부 기능은 구현되어 있으나 전체 통합 엔진·카탈로그·exporter는 설계 단계입니다.
단말/워크로드 증거는 별도 검토가 필요합니다. 영어 문서의 도표와 현황 구분을 함께 참고하세요.
