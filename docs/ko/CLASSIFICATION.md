# 분류 엔진

[English](../CLASSIFICATION.md) · [목차](README.md)

런타임의 결정적 분류와 분류 제안 생성을 분리합니다.
런타임은 정규화된 route/action → 바인딩 인덱스 → 활성 카탈로그 → 검증된 객체 근거를 통해
resource_id, 정보등급, 구획, 소유자, 필요한 의무와 미확인 근거를 반환합니다.

컴파일 시 충돌과 모호한 작업을 거부하고, 문자열·등급 벡터를 공유하는 불변 구조로 만듭니다.
요청마다 정규식 컴파일·파일 읽기·SQL·LLM·콘텐츠 크롤링을 하지 않습니다.
객체 조회가 필요한 정책에는 별도 기한과 실패 조건을 명시합니다.

콘텐츠 검사는 명시적인 타입·크기·시간 예산이 있는 작업이어야 합니다.
대용량 본문 전체를 매번 버퍼링하거나 민감한 바이트를 먼저 전달하고 나중에 검사하지 않습니다.
애플리케이션 분류나 비동기 분석이 더 적절한 경우를 구분합니다.

LLM/외부 스캐너는 버전·근거·범위·만료·검토 상태를 갖는 제안만 만듭니다.
제안 → 소유자 검토 → 영향 분석 → 승인 → 컴파일 → 관찰 검증 → 게시 순서로 갑니다.
미검토 결과가 자동으로 등급 하향·허용 목록 수정·ASN 차단 확대를 하게 하지 않습니다.
본문 변환 뒤에는 이전 바이트에 대한 검사 증명을 재사용하지 않습니다.
