# 공통 콘솔 플러그인

[English](../CONSOLE.md) · [목차](README.md)

Guard·Hopae는 Hangang 사이드바 메뉴/서브메뉴로 들어갑니다.
공통 셸·테마·언어·로그인을 사용하고, 플러그인 내부에 별도 로그인 화면을 중복하지 않습니다.
기존 콘솔로 도메인을 연결하는 것만으로 메뉴가 설치되는 것은 아닙니다.

운영자가 검토한 패키지는 manifest, UI 모듈, 파일 해시와 명시적인 API 목록을 갖습니다.
Hangang이 검증된 파일을 같은 출처의 /ui/plugins/<id>/ 경로에 제공하고 import()로 가져옵니다.
플러그인은 root·API broker·언어·취소 신호·수명주기 기능을 받습니다.
서비스 토큰과 내부 백엔드 주소는 브라우저에 제공하지 않습니다.

같은 출처의 자바스크립트는 관리자 콘솔 권한을 가진 신뢰 코드이며 sandbox가 아닙니다.
임의 외부 JS URL은 허용하지 않고 설치 해시를 고정합니다.
로그아웃·권한 회수 때 요청을 취소하고 DOM을 비우며 이전 응답이 새 세션을 덮지 않도록 합니다.
이동 시 폴링을 멈추고 같은 세션의 초안은 유지합니다.

서버가 매 요청의 계정·역할·등록된 작업을 검사합니다.
처음 Guard 플러그인은 관리자 전용이고 viewer/세부 권한은 별도 작업 계약으로 확장합니다.
관리 API가 네트워크 수집/판단 API까지 무제한 중계하지 않습니다.

기존 운영 Hangang의 계정/API를 재사용하는 콘솔 어댑터를 둘 수 있습니다.
새 사용자 DB를 복제하지 않고 기존 신원 API에서 권한을 재검증하며 일반 관리 호출은 원래 API가 처리합니다.
실제 작업자와 결과 불확실성을 감사 기록으로 남깁니다. Hopae의 위임 권한은 별도 설계·검증합니다.
