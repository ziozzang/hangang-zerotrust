# 단말·워크로드: 미해결 설계

[English](../DEVICES.md) · [목차](README.md)

단말·워크로드는 추가 고민이 필요한 항목으로 명시합니다. 에이전트를 필수로 설치하거나
확인하지 않은 장치를 정상으로 판정하는 작업을 자동으로 시작하지 않습니다.

사용자 세션·IP·관리 단말·워크로드 인증서는 서로 다른 근거입니다.
인증서는 수락된 키와 신원 바인딩을 확인할 수 있지만 OS 패치·하드웨어 상태·비침해 실행을 자동 증명하지 않습니다.
현재 Hangang의 mTLS/워크로드 기능은 계약 검토 뒤 재사용할 수 있습니다.

MDM/기존 단말 관리, 에이전트, 워크로드 발급자/mTLS, 브라우저 키 바인딩 등을 비교합니다.
각 방식의 신뢰·갱신·회수·BYOD·개인정보·오프라인 운영·유지 비용을 먼저 정합니다.

향후 증거 계약은 발행자·대상·주체/장치 바인딩·증거 종류·발급/만료·권한 epoch·검증 방법·회수 참조를 갖습니다.
정책이 검증된 단말 상태를 요구하는 경우 증거가 없거나 오래되면 거부합니다.
요구하지 않는 정책은 자신의 명시적인 근거로 운영할 수 있습니다. 미확인을 healthy로 바꾸지 않습니다.
