# 품계·수문장·호패 통합 검증

2026-10-13 Linux 운영 반영 검증 완료. Hangang #5, Guard #2, Hopae #3가 머지되었고
품계 저장소는 공개되었습니다. 영어 상세 증거표는 [검증 기록](../PUMGYE_QUALIFICATION.md)에 있습니다.

품계의 제한된 불변 정책·서비스/사용자/IP 권한·정보등급·AAL을 검증했습니다.
인증 후 guest/미선언 메서드/네트워크 근거 누락을 거부하고, 수문장 observe·장애·
fail-open이 필수 집행을 우회하지 않습니다. 헤더 위조·네임스페이스·보호 해제 경계도
검증했습니다. 기존 Hangang 설정 권한·CAS·감사를 통해 정책을 게시합니다.

Rust 702건 통과(라이브러리 제외 13건), 브라우저 8건 통과. 배포 정적 바이너리의
HOP1/HGD1 실 프로세스에서 허용·guest/observe/차단 거부, CAS 충돌, 정책 철회 시
1.5초 이내 스트림 종료와 이후 요청 거부를 확인했습니다. SSO 실 프로세스도 통과했습니다.
운영 HTTPS에서 세 메뉴·매트릭스 조회·호패 위임 관리·SSO·로그아웃 정리와 인증된
수문장 프로토콜을 확인했습니다.

첫 배포는 토큰 환경변수 참조 불일치로 외부 준비 검사를 통과하지 못해 자동 복구됐습니다.
명시적 참조로 수정한 재배포와 실 검증이 통과했습니다. 운영 계정·서비스 배정·네트워크
역할·집행 모드는 자동 변경하지 않았습니다. 기존 수문장 observe 정책을 유지하므로
수문장을 필수로 요구하는 새 품계 게이트는 observe를 허용 근거로 수용하지 않습니다.

새 서명 멀티플랫폼 릴리즈가 아닌 검토된 Linux 기능 배포입니다. 플랫폼 CI는 별도 추적하며
기존 릴리즈/업데이트 호환성을 유지합니다. 종단간 HTTP 10만 QPS 또는 긴 스트림의
지속적인 프로바이더 세션 철회를 입증했다고 주장하지 않습니다. 모든 설정 게시에
품계 스트림을 보수적으로 철회합니다. 장부·기존 사초·실록·사헌 런타임은 요청 범위대로
설계 단계에 둡니다.

## 수문장 실행 파일·릴리즈 완료

2026-10-13 Guard #3 머지 및 [수문장 v0.3.2](https://github.com/ziozzang/hangang-guard/releases/tag/v0.3.2)
공개 완료. main CI 38322290197에서 네 플랫폼이 모두 통과했습니다. 업로드된 22개
자산의 크기와 GitHub SHA-256을 대조했고 기본/호환 서명 쌍을 Ed25519 공개키로
독립 검증했습니다.

운영 실행 파일은 `sumunjang 0.3.2`이며 게시된 검증 Linux 자산과 해시가 일치합니다.
운영 설정 사전 검사·네이티브 리스너·교체 후 통합 콘솔/SSO 검증을 통과했습니다.
실제 감독형 GitHub 업데이트 확인 결과는 `up_to_date`입니다. 격리된 실제 v0.3.1
클라이언트가 실제 v0.3.2 호환 실행 파일로 업그레이드하고 정책 보존·롤백·변조
거부 검증도 통과했습니다. 기존 저장소 URL·HGD1·자격 증명 이름은 유지하며
`hangang-guard`는 명시적 호환 실행 파일로 제공합니다.
