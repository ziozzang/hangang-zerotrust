# 위협 모델과 검증

[English](../THREAT_MODEL.md) · [목차](README.md)

클라이언트는 경로·헤더·쿠키·본문·타이밍을 조작하고 오래된 메시지·큐 폭주·부분 장애를 만들 수 있습니다.
다운로드/분석 대상이나 낮은 권한의 제안 생산자가 침해될 수 있습니다.
설치된 관리자 JavaScript는 신뢰 코드이며 자동으로 격리되는 것은 아닙니다.

확인할 불변 조건: 서버 권한 주체의 신원/분류만 사용, 하나의 보호 네임스페이스,
승인된 등급 하향과 새 리비전 롤백, IP 허용과 사용자 권한 분리, 연결마다 아닌 요청마다 권한 확인,
이전 UI 응답 제거, 검토된 해시 패키지, 서비스 토큰 비노출, 필드/작업 범위 위임,
프레임 길이/ID/회수·파서 동등성, 요청 경로의 분석 DB 비의존, 감사 한도와 결과 불확실성,
고카디널리티/민감 정보 제한, 외부 인증 장애 시 신원 위조 금지입니다.

실제 프로세스, HTTP/native 골든 사례, 동시 권한 변경, 재기동·포화 검증이 필요합니다.
스키마 검사·단위 테스트·스크린샷만으로 운영 전체 보장을 주장하지 않습니다.
