## Navigation decision

Keep Hangang as the console shell and gateway/routing owner. Current source
already groups the three authorities under Zero Trust. Make ordering host-owned:
**Identity · Hopae → Network trust · Sumunjang → Authorization · Pumgye**.
Keep stable IDs and old hashes, including `guard`, as compatibility aliases.
Disambiguate console accounts from Hopae identities and Pumgye service assignments.
Use the existing River theme and tokens rather than another UI framework.

The common page skeleton is breadcrumb, functional title/owner description,
actions, authority/source/freshness/revision strip, subnavigation and task content.
The global Hangang connection/revision must not imply every authority is healthy
or that access is allowed. Missing, zero, stale, disabled, read-only and unavailable
are distinct states. Future Jangbu/Sacho observability and Saheon/Sillok evidence
areas remain design slots until real installed, authorized capabilities exist.

## Source-established defects and limits

Hangang's return navigation reloads Pumgye and resets its dirty draft. Hopae's
resume/tab load replaces untracked editors. Responses to a save can also replace
new edits made while it was in flight. Plugin sections append after the shell
footer. Pumgye borrows very small monitoring-table styles; plugin locale/tab
semantics are inconsistent. These require executable fixture regressions before
claiming fixes.

Guard currently accepts full policy replacement without a caller revision;
serial engine writes do not detect stale drafts. Its separate allowlist GET→PUT
also has a race. This is an authorized lost update, not a demonstrated
authentication bypass. Host post-dispatch revocation can redact a completed
mutation's response and discard its operation reference. Keep the final authority
fence; fix outcome reporting without leaking the revoked payload. Native backend
authorization refusal must be distinguished safely from infrastructure failure.

Current host plugin discovery/API is administrator-only. Changing button or menu
visibility cannot add viewer privileges. Native Hopae authority and explicit
Hangang delegation are different modes, not fallback alternatives. Pumgye's
backend audit peer is not by itself the browser human actor. Preserve those
boundaries and correlation while improving the UI.

and `style.css`; Hopae `plugins/hopae/index.js`; Sumunjang dashboard source and
`tools/build_console_plugin.py`. Guard package files are generated: editing only
their output will be overwritten. Regenerate the package and pin its reviewed
manifest hash together with lifecycle/layout changes.

Extend existing console, Pumgye, plugin lifecycle and localization fixtures.
Browser captures must use reserved fixture data and identify exact source/build.
Cover light/dark, EN/KO, representative desktop/mobile layouts, keyboard flows,
stale/empty/conflict states and role loss. Real owner API concurrency and
post-dispatch mutation tests complement visual tests. Full reviews and follow-up
implementation plans are retained in the private review archive; the
