# Actual owned Service/browser qualification

This helper uses the actual compiled gateway UI, real installed reviewed plugin files and real owning APIs. It NEVER intercepts/fulfills API responses or replaces browser clocks. Source basis: exact Rootf45 actual-browser helper, plus approved039 ADM04 host-navigation assertions. Current ZT runner ownership/UID/backup rules are retained.

Use current `tools/kubernetes_world_smoke.py --browser-probe <this-directory>/world_admin_browser.mjs --host-navigation --plugin-locale --pumgye-responsive` with both reviewed plugin packages and complete Service/observed/projection arguments. `--workload` is explicitly unsupported; this is not WorkloadUI acceptance. `--host-navigation` retains actual compiled authority order/ENKO menu labels, Pum subaddresses/Back/Forward/reload/account state/search/uninstalled route refusal. `--plugin-locale` checks installed Hop profiles and Sum diagnostic draft fields across repeated ENKO transitions: exact retained DOM node, retained unpublished draft, no new plugin owner calls, translated controls, unchanged native read-only policy controls. Original local editor values are restored without publication. Sum diagnostic draft is not an edit to native owned policy. Locale tests do not create/delete or publish a profile/policy.

The existing full browser flow still intentionally mutates ONLY owned namespace fixtures (first-admin setup, Pum guest grant, Sum operator CRD block/unblock, Hop profile CAS/restart/restoration/logout). Parent owns explicit cluster authorization. No operator/production namespace is eligible.

Runtime requires Node + existing `@playwright/test`/Chromium. For a standalone isolated checkout, install approved dependencies or create a disposable ignored `node_modules` link to the already qualified web dependency tree; no dependency link is committed. Commands and parent approval stay separate from tests. A gateway-only image is sufficient because Root embeds /ui assets; standalone hangang-console proxy/SSO is a separate gate.

Local checks: `node --test *.test.mjs`, node --check, Python fake-renderer/prerequisite regressions. These test helper invariants and CLI wiring, NOT live backend acceptance. Live PASS is emitted only when the actual authorized browser run executes these assertions. Inflight publication/cancellation/role-withdrawal locale races and actual Workload policy UI remain separate unimplemented live fixtures; mocked Playwright API tests are not counted as those gates.

The native Sum panel is fully mounted, then hidden through ordinary host navigation to pause its legitimate five-second status poll; locale must still update its cached mounted DOM. It is shown again afterwards. No fake clock or network interception is used.
